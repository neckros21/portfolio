# Réalisations — Alexandros D.

Page portfolio qui présente mes sites vitrines démo (boulangerie, artisan, coiffure).
Réalisée par **Alexandros D.**, développeur web à Bruxelles.

## Stack

- Next.js (App Router) + TypeScript
- Tailwind CSS
- Motion (animations) + Lenis (défilement fluide)
- SEO : métadonnées, Open Graph, sitemap, robots, données structurées `Person`

## Lancer en local

```bash
npm install
npm run dev
```
